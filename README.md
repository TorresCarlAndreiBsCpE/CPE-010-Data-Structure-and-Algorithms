# COURSE DESCRIPTION
- This course focuses on solving computational problems that manipulate collected data, studying a core set of data
abstractions, data structures, and algorithms that provide a foundation for writing efficient programs. The course content
includes theoretical topics in algorithmic efficiency and complexity, along with abstract data types, including graphs, networks,
trees (including binary and multi-way trees), heaps, stacks, and priority queues. Search topics, including hashing, trees,
external search trees (B-trees), and fundamentals of sorting algorithms with external sorting are introduced and compared. The
student's outcome is to design algorithms for each data structure and to use data structures and algorithms in the design of an
effective program or software application that will solve a particular engineering-related problem using C++

# COURSE OBJECTIVES
- The course aims to provide an understanding of analyzing algorithms and their complexity. It also allows the development of data structures including Abstract Data types, Linked Lists, Stacks, Queues, Trees, and Graphs using the C++ programming language. Additionally, use mathematical techniques to analyze the efficiency of the various algorithms presented, as well as the common operations on the data structures discussed. The course also allows students to implement algorithms and conduct real-system performance measurements and analyses using the C++ programming language. This course aims tocontribute towards the attainment of SDG 9 – Industry, Innovation, and Infrastructure.

# COURSE TOPICS

# PRELIM
I. Course Introduction: TIP Vision and Mission; TIP Graduate Attributes/Institutional Learning Outcomes; Program Educational
Objectives / Student Outcomes; Course Syllabus and Course Requirements; Orientation for Industry and Laboratory
Software and Tools.
II. Introduction to Data Structures and Algorithm Analysis: C++ Programming Review, Abstract Data Types, Space and Time
Complexity, Algorithm Analysis Techniques
III. Arrays and Linked Lists: Dynamic Memory Allocation, and Singly, Doubly and Circular Linked Lists
IV. Stacks: Stack using Array, Stack using Linked Lists, Implementation in C++, Problem Solving

# MIDTERM
I. Queues: Queues using Arrays, Queues using Linked Lists, Implementation in C++, Problem Solving
II. Searching Techniques: Linear Search, Binary Search, Hashing
III. Sorting Algorithms: Basic Sorting Algorithms

# FINALS
I. Tree ADT; General and Binary Search Trees; AVL Tree; Traversal Algorithms; Solving Problems using Trees.
II. Graph ADT; Adjacency Matrix and Adjacency List; Breadth-First Search; Depth-First Search; Solving Problems using Graphs.
III. Basic Algorithm Analysis; Theoretical and Experimental Methods in Measuring Time; Time Complexity Classes.
